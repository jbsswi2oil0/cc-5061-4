启动说明 / 支持范围

启动界面：在 /workspace 目录执行 python3 app.py，浏览器打开 http://127.0.0.1:8000（可用 PORT=8123 python3 app.py 改端口）。

支持的运动模型：初版仅支持相似变换（平移 / 旋转 / 统一缩放，近似平面相机运动）与可选仿射变换（平面运动）。 视差明显时会给出逐帧模型残差与告警——单一 2D 变换不能解释所有深度。

视野取舍：黄色多边形是原片里实际被采样的有效区域。最低视野保留下限限定最大放大； 当理想平滑需要的裁切超过该上限时，内核会在局部回退校正强度（“牺牲稳定度”），而不是偷偷放大或留下黑边。

平滑是对累计相机路径做低通，保留有意的缓慢运镜与真实运动的时间顺序，不是冻结画面。

0 = 关闭，100 = 最强低通（不冻结运镜）

怎么读这个播放器

  • 左图黄色多边形：当前参数下原帧中被采样进输出的区域（有效区域 / 裁切边界），随平滑强度与视野下限逐帧变化。
  • 拖动平滑强度：轨迹图与黄框由内核规划接口即时重算；停顿后自动重新渲染右侧完整视频。
  • 红点 / 红区：受最低视野上限所限，该帧局部回退了校正（牺牲稳定度）以杜绝黑边。
  • 点击任一图表可把双画面跳转到对应帧；播放时竖线为当前帧。
